5. Public data sources

At runtime the extension also reads live public data. These are external services, not bundled code — they carry no license obligations, but we credit them for transparency. Every record queried or scraped through these services is publicly available data (domain-registration records, public DNS and certificate-transparency data, and publicly distributed security lists), and requests contain only the URL, IP address, or domain being evaluated — never personal data:

  • Domain registration — registry RDAP servers (resolved from the IANA RDAP bootstrap), the rdap.org RDAP aggregator, and the free public WHOIS page who.is (used only as a last resort for registries without RDAP, e.g. .hu, .us, .se, .it, .ru).
  • Certificate transparency — crt.sh, with Cert Spotter as a keyless fallback.
  • DNS — public DNS-over-HTTPS (Cloudflare, Google).
  • Threat intelligence — URLhaus, Feodo Tracker, OpenPhish, PhishStats, Phishing.Database, Destroylist, Phishing Army, IPsum, blocklist.de, GreenSnow, DShield, SSLBL, Spamhaus DNSBL, ransomware.live.
  • Breach checks (user-initiated) — HaveIBeenPwned.

Each provider operates under its own terms and privacy policy; see the Privacy Policy.
