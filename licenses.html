The "Phishing corpus" by Jose Nazario (monkey.org/~jose/phishing) is licensed under the Creative Commons Attribution 4.0 International license. The messages were adapted — parsed and normalized into a machine-learning training set — to train the on-device classifier. The raw messages, full headers, and attachments are not redistributed with PhishDiver; only the trained model is distributed. Full change indication and the license reference are provided in LICENSES/CC-BY-4.0-Nazario-Corpus.txt inside the extension.

CC0 1.0 notice for phishunt.io

The phishing URL feed from phishunt.io (by Daniel López) is released into the public domain under the Creative Commons CC0 1.0 Universal dedication. phishunt.io explicitly welcomes use of its data in blocklists and LLM/model training. The feed is adapted — URLs are parsed and normalized into a training set — so only the trained model is distributed. Attribution to phishunt.io is appreciated but not required.

MIT license for Phishing.Database

The active phishing URL and domain lists from Phishing.Database (maintained by mitchellkrogza / Phishing-Database) are used to build the URL classifier's positive training set and to power the runtime Phishing.Database threat feed (exact URL = danger, domain match = danger). They are released under the MIT License, which permits commercial use with attribution. The lists are adapted — URLs and domains are parsed and normalized into a training set and in-memory lookup sets — so only the trained model is distributed.

MIT license for DigitalSide Threat-Intel

The malware URL and domain lists from DigitalSide Threat-Intel (maintained by davidonzo, osint.digitalside.it) are Open Source Cyber Threat Intelligence derived from malware analysis — unique malicious URLs and domains observed in the last 7 days, refreshed daily. They are released under the MIT License, which permits commercial use with attribution. The URL list is adapted — URLs are parsed and normalized into the URL classifier's positive training set — and the same lists back the runtime DigitalSide threat feed (exact URL = danger, host match = warning), replacing the URLhaus feed that abuse.ch now restricts to not-for-profit use.

MIT license for the Tranco list

The Tranco top-1M ranking (tranco-list.eu) is used to sample legitimate (negative) URLs for the URL classifier. The list is released under the MIT License; a copy of the license text is included in LICENSES/MIT-Tranco.txt inside the extension, with attribution to the Tranco project.

6. Public data sources

At runtime the extension also reads live public data. These are external services, not bundled code — they carry no license obligations, but we credit them for transparency. Every record queried through these services is publicly available data (domain-registration records, public DNS and certificate-transparency data, and publicly distributed security lists), and requests contain only the URL, IP address, or domain being evaluated — never personal data:

  • Domain registration — registry RDAP servers (resolved from the IANA RDAP bootstrap) and the rdap.org RDAP aggregator. Registries with no RDAP anywhere (e.g. .hu, .us, .se, .it, .ru) report the registration date as unavailable.
  • Certificate transparency — crt.sh, with Cert Spotter as a keyless fallback.
  • DNS — public DNS-over-HTTPS (Cloudflare, Google).
  • Threat intelligence — phishunt.io, TweetFeed, Phishing.Database, DigitalSide, Destroylist, IPsum, Blocklist Project, blocklist.de.
  • Breach checks (user-initiated) — HaveIBeenPwned.

The TweetFeed IOC feed is published by Daniel López under the Creative Commons CC0 1.0 Universal public-domain dedication (no attribution required). The HaveIBeenPwned public breach list used by the breach checker is published by Troy Hunt under the Creative Commons Attribution 4.0 International license (CC BY 4.0); HIBP's terms request that for-profit applications relying on HIBP data at scale use a paid subscription — the checker runs user-initiated, keyless lookups and never forwards your email or domain to HIBP through the extension (email checks open HIBP directly; the domain checker filters the public list locally). The URL classifier is trained on phishunt.io (CC0 1.0), Phishing.Database (MIT — used for training and as a runtime URL & domain feed), and the Tranco top-1M ranking (MIT). Attribution for all threat sources is provided on the extension's About page.
