2. Training data (not redistributed)

The on-device model shipped with the extension is a trained TF-IDF + logistic-regression classifier. The raw source messages are not distributed — only the trained model file is shipped.

Data sourceLicenseCopyright / CreatorUse
Jose Nazario "Phishing corpus" CC BY 4.0 Jose Nazario Positive (phishing) training examples
Apache SpamAssassin public "easy ham" corpus Freely redistributable public corpus; message copyrights remain with original senders Apache SpamAssassin project and message authors Negative (legitimate) training examples
Enron Email Corpus (CMU mirror) Released publicly by the Federal Energy Regulatory Commission during its 2003 investigation FERC and the original Enron Corp. email authors Negative (legitimate) training examples — workplace ham
CC BY 4.0 attribution for the Nazario corpus

The "Phishing corpus" by Jose Nazario (monkey.org/~jose/phishing) is licensed under the Creative Commons Attribution 4.0 International license. The messages were adapted — parsed and normalized into a machine-learning training set — to train the on-device classifier. The raw messages, full headers, and attachments are not redistributed with PhishDiver; only the trained model is distributed. Full change indication and the license reference are provided in LICENSES/CC-BY-4.0-Nazario-Corpus.txt inside the extension.

3. Development-time tools (not shipped)

The training pipeline runs on standard Python packages during development only; none of these are bundled in the extension: scikit-learn (BSD 3-Clause), skl2onnx (Apache 2.0), onnx (Apache 2.0), onnxruntime Python (MIT).
